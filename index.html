  • • הציון כנקודת סיום שאינה מאפשרת תיקון וצמיחה.
הערכה לשם למידה (תפיסת תשפ"ז)

  • • שבירת המשוואה "הערכה = מבחן" לטובת תוצרים מגוונים.
  • • דגש על טיוטות, משוב מצמיח ושיפור מתמיד.

פרק 05 // ארגז כלים להערכה

הצגת מדדי הערכה אלטרנטיביים למטלות אפשריות

1. תהליך והתמדה

עמידה באבני דרך, הגשת טיוטות בזמן, והטמעת הערות המשוב בגרסה הבאה.

2. מיומנויות חשיבה

שאילת שאלות פוריות, השוואה בין מקורות, זיהוי נקודות מבט וביסוס טיעון מנומק.

3. יצירתיות וחיבור אישי

מקוריות ההגשה, חיבור רגשי/ערכי לטקסט ורלוונטיות למציאות העכשווית.

4. אוריינות ותקשורת

משלב לשוני עשיר, בהירות הכתיבה, פרזנטציה בעל-פה ועבודת צוות.
